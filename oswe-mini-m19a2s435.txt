## Notable Design Decisions & Tips 💡

- I preserved the original code in user_display_original.py to keep a reference and avoid accidental regressions.
- `_safe_get()` returns `"<missing>"` where keys are absent; this keeps output stable and logs a warning.
- `build_user_index()` allows efficient repeated lookups. The default `get_user_by_id(...)` creates a temporary index when none is provided.
- Logging uses the `MARKER` constant for easy filtering in logs (e.g., capture `[USER-DISPLAY]`).
